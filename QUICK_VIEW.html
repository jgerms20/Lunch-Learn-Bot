⚠️ How to Access the Full Dashboard

Since this system runs in a remote environment, you'll need to access it on your local machine:

  1. Clone the repo to your local machine: git clone <repo-url>
  2. Navigate to the folder: cd Lunch-Learn-Bot
  3. Start the server: python3 -m http.server 8000
  4. Open browser to: http://localhost:8000/dashboard/

Or copy the entire folder to your OneDrive and access it from any device!

🎯 Quick Start Guide

1. Run Partner Suggestions

Get intelligent partner recommendations:

python3 suggest-partners.py

2. Use Claude Skills (Cross-Device!)

These work on desktop app, web, mobile, anywhere you use Claude:

  • Draft Outreach Email: "Draft an outreach email for [COMPANY] about [TOPIC]"
  • Generate Internal Invite: "Generate internal invite for [COMPANY] L&L on [DATE]"
  • Research Contact: "Research contact at [COMPANY]"
  • Suggest Partners: "Suggest partners for [VERTICAL]"
  • Summarize Audio: "Summarize this audio/voice note"

3. Follow the Workflow

See docs/WORKFLOW_GUIDE.md for complete step-by-step from ideation to post-event.
